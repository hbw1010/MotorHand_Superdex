# MotorHand 离线回放记录

基线 `2dd8f3f074740cb0c177304d8b44497b7a62f5d2`；固定腕部、掌心锁定、尺寸 89 mm；默认 C++ 物理步进与 Python 反馈合成，FP32，物理步长 1/240 s，最多 4 个子步且按实时预算提前结束，控制周期 100 Hz。demo 没有串口下发。使用 DemoGlove 的完整 12 轴输入：每 0.2 s 将 grip 从 0 到 0.8 以 0.05 递增、保持 2 s、对称松开；各阶段及实际角度、物理输出保存在压缩 JSONL。保存的角度与场景为约 10 Hz 网页采样，并非 100 Hz 全量接触帧；这里的覆盖率和指标只适用于采样数据，不能替代完整帧验收或固定仿真时间复现。

重建同帧分析及图：

```bash
.venv/bin/python tools/experiments/motorhand_offline_analysis.py
```

重新采集正常入口（约半分钟，实时调度与具体结果会变化）：

```bash
.venv/bin/python tools/experiments/motorhand_offline_replay.py --profile nominal --output /tmp/motorhand-nominal
```

正常 demo 入口选择配置：

```bash
.venv/bin/python tools/ve33_g4_view.py --local-grasp --demo --feedback-profile nominal
.venv/bin/python tools/ve33_g4_view.py --local-grasp --demo --feedback-profile identity
```

三个物体均 96/96 个网页样本含合成所需字段。硬方块 J5 原始投影中位数 −0.277451 N·m、位置项 −2 N·m，实际接触包括 `index_pip_link`；没有拿其他轴补足 J5。配置曲线以此采样稳态拟合锚点 0.27745119178421784→5 N·m；该工程初值基于有限采样，需后续完整轨迹核验。软球保持末端包围盒世界 Z 跨度 86.28 mm，释放后 89.00 mm，说明本次可观测到形变和回弹；几何与接触点不同会影响软硬比较。曲线比较不是固定仿真时间回放，也没有独立的浅握或慢速验证。

另一次正常入口 nominal 重放使用当时的 `[0.28, 5.0]` 锚点，硬方块 J5 原始投影 −0.278112、位置项 −2、名义值 −6.961714 N·m（末 1 秒中位数），与同帧离线试验是不同物理运行，不能用于证明物理轨迹完全一致。原始 `nominal-*.jsonl.gz` 与 `identity-*.jsonl.gz` 分别保留。采集期间物理帧并未冻结，无法据此判断映射本身对物理接触或形变的影响。

构造的 100 Hz 合成层事件在 1.00 s 单帧注入；初始 J5 恒定 −0.28 N·m、输入 0.80 rad、仿真 0.71 rad。单零反力及 0.06 rad 回撤使输出即时归零，恢复后依次约 −0.475、−1.049、−1.644 N·m；正反翻转使该帧输出转正，再恢复负载时重新建力。两条不同原因可产生类似曲线，不能据此认定真机振源。完整序列在 [synthetic-events.json](synthetic-events.json)。这是构造输入，不是佩戴闭环测量。

## 真机预览链路调整

真机抓握时观察到接触帧年龄偏高，并发生“仿真使用的编码器样本过期”中断。本地抓握现在以 100 Hz 为物理循环目标，网页场景和接触可视化最多约 30 Hz，场景或接触版本变化时立即更新。物理帧仍使用实际驱动该步的编码器时间，原 100 ms 指令期限和过期保护不变。已关闭多余的 demo 实例，避免它与真机仿真同时争用 CPU。

出力关闭的 90 mm 软球预览录制 8 秒得到 794 个控制采样、622 个不同物理帧，物理帧间隔中位数 12.81 ms、P95 14.31 ms，接触帧龄中位数 24.93 ms、P95 35.12 ms，录制丢弃 0。该结果不是佩戴出力下的断联率或严格的同输入前后对照；出力时仍需监测帧龄、中断及手感。
