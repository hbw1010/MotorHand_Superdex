# MotorHand 本地抓握实施计划

这是 2026-11-19 的实施记录。当前需求、链路和标定状态见 [MotorHand VE33 力反馈需求与当前进展](../../motorhand-force-feedback.md)。

**目标** 使用 SuperDex 与现有 G4 混合力反馈，在桌面网页完成参考 sim 的掌心和桌面抓握。

**约定** 固定虚拟腕部，使用已标定的 12 轴编码器。默认 45 mm 软球，尺寸 20–90 mm。软球使用体积弹性，软方块和软圆柱使用柔顺接触。真实接触和同向角差共同决定反馈，保留 ±9.5 N·m、100 ms 指令有效期及手动启停。演示模式使用本地合成角度，无串口输出。

- [x] 场景物体。测试六种模型、尺寸与参数校验、软球释放回弹、对象锁定和重置。实现 `LocalGrasp`，通过 `configure_grasp` 合并经验证的设置。
- [x] 本地服务。增加 `--local-grasp`，复用 12 轴采集、接触投影与反馈。物理线程应用场景设置，刷新接触句柄，发布同一帧的物理位置、实际接触及软球表面。
- [x] 网页。复用本地控制台，提供物体、尺寸、硬度、旋转、锁定、桌面移动、复位，实时更新软球表面。CSV 由后台写入控制周期采样，网页下载完成的记录。
- [x] 离线验收。36 项回归通过。Chrome 验证三维模型、桌面拖动、旋转、锁定、归位、记录和下载。软球握紧时横向缩小约 1.5 mm，松手后物理反力与合成力矩归零。伪 G4 验证 12 轴采集、接触前馈、超时和恢复、网页显式停止。
- [ ] 实机验收。当前系统没有 G4 串口。接回手套后核对 12 轴与零位，再测佩戴手感、方向和实际电流。
