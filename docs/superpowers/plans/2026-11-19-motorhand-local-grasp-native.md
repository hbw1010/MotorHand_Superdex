# MotorHand 本地抓握 C++ 实施计划

这是 2026-11-19 的实施记录。当前版本的默认后端和力矩合成入口见 [MotorHand VE33 力反馈需求与当前进展](../../motorhand-force-feedback.md)。

**目标** 降低固定腕部抓握的逐帧开销，并维持现有网页、反馈语义与指令时效。

**方案** 通过匹配当前 SuperDex 安装的公开 C++ 接口，在同一进程批量执行子步、关节回读、力和雅可比采样。将接触力和位置补偿的合成移入同一原生模块。现有 CAD 闭链校验、场景配置、网页和 G4 启停继续由原入口负责。

- [x] 扩展通过公开 C++ 接口访问当前 SuperDex 场景和关节。同一物理帧的角度、角速度、接触和投影验证一致。
- [x] 本地抓握默认使用 C++ 步进、接触投影采样和合成力矩。
- [x] 验证 256 帧逐轴数值对照、释放归零、90 mm 软球、桌面拖动旋转复位和伪串口超时恢复。
- [x] 本机采样与投影约 811 → 63 µs，合成约 58 → 13 µs。90 mm 软球接触帧龄中位数约 31 → 21 ms，P95 约 41 ms，两版各 140 次有效。当前网页演示已切换，运行方式见 G4 README。
